| 항목 | 내용 |
|---|---|
| 기간 | 3주차 (7일) |
| 목표 | 프롬프트/모델 비교 실험 + 결과 시각화 + 자연어 감사 리포트 생성기 완성 |
| 완료 기준(DoD) | ① 비교 실험표 확정 ② 차트 이미지 3종 ③ 샘플 감사 리포트 3건 생성 |

## 0. 3주차를 한 문장으로

> **"판별기를 '실험'으로 검증하고, 결과를 '보여줄 수 있게' 만든다."**

2주차엔 판별기가 '작동한다'를 보였습니다. 3주차는 두 가지를 더합니다.
하나는 **실험** — "이 프롬프트가 저 프롬프트보다 낫다", "이 모델이 더 싸고 비슷하다"를
숫자로 비교합니다. 다른 하나는 **전달** — 표와 차트, 그리고 사람이 읽는 감사 리포트로
만들어, 면접관이 30초 안에 이해하게 합니다.

이 주차가 "학생 프로젝트"와 "실무형 프로젝트"를 가르는 구간입니다.

## Step 1. 프롬프트 전략 3종 비교 — 🤖 코드 / 🙋 실행

**목적**: "프롬프트를 어떻게 짜느냐"가 성능을 얼마나 바꾸는지 실증. 면접 단골 질문
("프롬프트 엔지니어링 해봤나요?")에 숫자로 답하기 위함.

비교할 3가지 전략:

| 전략 | 설명 | 기대 |
|---|---|---|
| A. zero-shot | 지금처럼 OWASP 정의만 주고 판별 | 기준선 |
| B. few-shot | 정답 예시 2~3개를 프롬프트에 포함 | 애매한 케이스 개선 기대 |
| C. 규칙힌트 주입 | 규칙 엔진 결과("이 부분이 의심된다")를 힌트로 함께 제공 | 재현율↑ 기대 |

**산출물**: 전략별 Precision/Recall/F1/FPR + 난이도별 재현율 표.
**리스크**: 3전략 × 100건 = 300호출. → 캐싱 적용 + 필요시 표본 50건으로 축소해 비용 관리.
**🙋 하실 일**: `python -m experiments.prompt_compare` 실행 후 결과 공유. (과금: 약 1,000원 내외)

---

## Step 2. 모델 비교 (Haiku 4.5 vs Sonnet 5) — 🤖 코드 / 🙋 실행

**목적**: "성능을 위해 꼭 비싼 모델이 필요한가?"를 실측. 실무에서 반드시 나오는
비용-성능 트레이드오프 판단 능력을 보여줌.

| 모델 | 입력/출력 단가($/M) | 관전 포인트 |
|---|---|---|
| Haiku 4.5 | 1 / 5 | 싸다. 성능이 얼마나 떨어지나? |
| Sonnet 5 | 2 / 10 | 2주차 기준선 |

**산출물**: 두 모델의 성능 표 + "100건당 비용" + "F1 1점당 비용" 같은 효율 지표.
**해석 예시**: "Haiku 가 F1 0.0x 낮지만 비용 절반 → 1차 스크리닝은 Haiku, 애매한 것만
Sonnet 재검" 같은 2단계 파이프라인 제안으로 연결.
**🙋 하실 일**: `python -m analyzer.run --model claude-haiku-4-5-20251001` 실행 후 공유.
(과금: 약 250원)

---

## Step 3. 결과 시각화 (차트 3종) — 🤖 코드 / 🙋 실행 (무료)

**목적**: 숫자를 그림으로. README 와 발표자료에 바로 넣을 이미지 확보.

만들 차트:
1. **방법별 성능 막대차트** (규칙/LLM/하이브리드 × P·R·F1·FPR)
2. **난이도별 재현율 라인** (easy→medium→hard 로 갈수록 규칙은 급락, LLM·하이브리드는 유지)
3. **혼동행렬(confusion matrix) 히트맵** (하이브리드 기준)

**산출물**: `data/results/charts/*.png` 3종.
**리스크**: matplotlib 한글 폰트 깨짐 → 영문 라벨 사용 또는 폰트 지정으로 예방.
**🙋 하실 일**: `python -m viz.make_charts` 실행 후 이미지 확인. (무료)

---

## Step 4. 감사 리포트 생성기 — 🤖 코드 / 🙋 실행 (소액)

**목적**: 이 프로젝트의 '최종 산출물'. 서버를 넣으면 사람이 읽는 보안 감사
리포트(Markdown/HTML)가 나온다. 지금까지의 부품(수집→규칙→LLM→하이브리드)을
하나의 파이프라인으로 연결하는 단계.

리포트 구성:
- 요약: 검사한 서버/도구 수, 위험 등급 분포
- 위험 도구 목록: 도구명 / OWASP 코드 / 심각도 / **근거 인용** / 조치 권고
- 안전 도구 목록
- (선택) AI기본법 고영향 AI 안전성 확보조치 대응 체크리스트

**산출물**: `reports/*.md` 샘플 3건 (정상 서버 / 위험 서버 / 혼합).
**🙋 하실 일**: `python -m report.generate --server filesystem` 실행 후 공유.
(과금: 서버 1개 감사에 수십~백원)

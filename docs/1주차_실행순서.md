# 1주차 실행 순서 (터미널에 그대로 붙여넣기)

프로젝트 폴더에서 PowerShell 을 엽니다.
(폴더에서 `Shift + 우클릭` → "여기에 PowerShell 창 열기")

---

## ① 가상환경 만들고 활성화

```powershell
cd "C:\Users\User\Desktop\MCP Proj"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

> **Activate.ps1 실행이 차단되면** (실행 정책 오류)
> ```powershell
> Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
> .\.venv\Scripts\Activate.ps1
> ```
> 또는 CMD 를 쓰신다면: `.venv\Scripts\activate.bat`

프롬프트 앞에 `(.venv)` 가 붙으면 성공입니다.

## ② 의존성 설치

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## ③ [Step 2] 연결 테스트 — 가장 중요한 관문

```powershell
python scripts/test_connect.py
```

- 최초 실행 시 npx 가 패키지를 내려받느라 **30초~1분** 걸릴 수 있습니다.
- 성공하면 `read_file`, `write_file`, `list_directory` 같은 도구 이름과 설명이 출력됩니다.
- **출력 전체를 복사해서 공유해 주세요.** 실패해도 에러 메시지 그대로 주시면 됩니다.

## ④ uv 설치 (fetch / git 서버용)

```powershell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

설치 후 **새 PowerShell 창을 열어** 확인:
```powershell
uvx --version
```

> uv 설치가 안 되면 대안이 있습니다. `config/servers.yaml` 주석에 pip 방식이 적혀 있으니 알려주시면 바꿔드립니다.

## ⑤ Git 초기화 (수집보다 **먼저** 해야 합니다)

git MCP 서버는 대상 폴더가 실제 Git 저장소일 때만 뜹니다.
따라서 수집 전에 반드시 `git init` 을 먼저 실행하세요.

```powershell
git init
```

## ⑦ [Step 5] 첫 커밋

```powershell

```

